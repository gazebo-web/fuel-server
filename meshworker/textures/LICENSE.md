# Texture sets

The image textures used by `gz.texture(...)` are from [ambientCG](https://ambientcg.com), released under the [Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) license.

`sets.json` pins each asset by its ID and the SHA-256 of its 1K JPG download. `fetch.py` downloads and verifies them when the worker image is built, so the images themselves are not stored in this repository.
